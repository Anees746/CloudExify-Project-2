## Project Description

The Student Grade Management System is a command-line (CLI) application
developed in Python as part of the CloudExify Python Internship 2026.

The application allows teachers or administrators to manage student
academic records efficiently. Users can add new students, enter grades
for multiple subjects, search student records, edit grades, delete
students, generate class reports, and save all records in a CSV file for
future use.

The project demonstrates Python fundamentals including functions, loops,
lists, dictionaries, nested dictionaries, file handling, CSV handling,
sorting, input validation, and exception handling.

## Features

-   Add New Student
-   View All Students
-   Search Student
-   Edit Student Grades
-   Delete Student
-   Generate Class Report
-   Student Rankings
-   Pass/Fail Status
-   Save to CSV
